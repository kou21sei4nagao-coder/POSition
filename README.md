# POSition（レジ番メーカー・オフライン版）

シフト表を貼り付けると、9:00〜21:00のレジ番を1時間ごとに自動で割り当てるiPad向けアプリです。

## データの扱い
- 名前・シフト・スタッフ設定は、使っているiPadの中（ブラウザの保存領域）だけに保存されます
- 外部へデータを送る処理は入っていません（ページ内の設定で、外部サイトへの通信も禁止しています）
- GitHubに置くのはアプリ本体だけです。実名の入ったファイルはリポジトリに入れないでください

## 公開手順（GitHub Pages）
1. GitHubで新しいリポジトリを作る（例：`regiban`、Public）
2. このフォルダの中身をすべてアップロードする
3. リポジトリの Settings → Pages → Branch を `main` / `(root)` にして Save
4. 数分後に `https://ユーザー名.github.io/regiban/` で開けるようになる

## iPadへのインストール
1. 上のURLをSafariで開く
2. 共有ボタン → 「ホーム画面に追加」
3. 一度開いたあとは、機内モードでも動きます

## バックアップ
- スタッフ画面の「書き出し」で設定をファイルに保存
- 機種変更や別のiPadでは「読み込み」でそのファイルを選ぶと復元

## 割り当てルール
- レジに入るのはPNと副リーダーのみ（リーダー・店長は入らない）
- レベル1（優先）→ 2（普通）→ 3（足りない時だけ）の順
- 4部門が均等になるように回す。部門のフロアが0人になる人は外す
- 同じ人の連続は基本避け、どうしても必要な時だけ2時間まで
- 時間帯をタップして担当変更・休憩で外すことができる

## 更新するとき
`sw.js` の `CACHE = "regiban-v9"` の数字を上げてからアップロードすると、iPad側に新しい版が届きます。
