# POSition（レジ番メーカー・オフライン版）

その日のシフトを貼り付けると、営業時間（初期設定は9:00〜21:00、「名簿」タブの「店の設定」で変更可）のレジ番を1時間ごとに自動で割り当てるiPad向けアプリです。アプリ内の「使い方」ボタンで説明を見られます。

## 使い方
1. 「名簿」タブ：シフト表のC列（名前）を一番上から一番下まで、部門の間の空白も含めてコピーして登録（最初の1回と、人が増減した時だけ）
   - シフト表の「早フル（8:30〜18:00）」「遅フル（12:00〜21:30）」のような言葉は、「店の設定」の「シフト表の言葉」で時間を決めて読む（v94〜）。それ以外の言葉（研修・応援・有給など）は休み
   - 登録し直したとき、新しく増えた人は見習い（レベル0）・同じグループの人たちの部門になる（v76〜）。違えば名簿で直す
2. 空白で区切られたグループごとに部門を選び、役職・レベルを設定
3. 「今日のシフト」タブ：作りたい日の列を、名簿と同じ行から同じ行までコピーして貼り付け
4. 照合結果で名前と時間がずれていないか確認し、「出力」

## データの扱い
- 名前・シフト・スタッフ設定は、使っているiPadの中（ブラウザの保存領域）だけに保存されます
- 外部へデータを送る処理は入っていません（ページ内の設定で、外部サイトへの通信も禁止しています）
- GitHubに置くのはアプリ本体だけです。実名の入ったファイルはリポジトリに入れないでください

## 公開手順（GitHub Pages）
1. GitHubで新しいリポジトリを作る（例：`regiban`、Public）
2. このフォルダの中身をすべてアップロードする
3. リポジトリの Settings → Pages → Branch を `main` / `(root)` にして Save
4. 数分後に `https://ユーザー名.github.io/regiban/` で開けるようになる

## iPadへのインストール
1. 上のURLをSafariで開く
2. 共有ボタン → 「ホーム画面に追加」
3. 一度開いたあとは、機内モードでも動きます

## バックアップ
- スタッフ画面の「書き出し」で設定をファイルに保存
- 機種変更や別のiPadでは「読み込み」でそのファイルを選ぶと復元

## 割り当てルール
- レジに入るのはPN・新入社員・No2・PNリーダー（リーダー・店長は入らない）
- 部門で「店長」「流通便」を選んだ人は、レジにもフロアの人数にも入らない
- 決める順番：手動で固定した時間 → 締め（20:00〜21:00） → 入れる人が少ない時間帯から
- 優先順位（上ほど強い）
  1. 閉店前の最後の1時間（締め）は「締め」にチェックした人（レベル1 → 2 → 3 → 4）。締めの人がいない日は、ほかの時間と同じ決め方にして警告
  2. 部門のフロアを0人にしない（見習い＝レベル0は人数に数えない。見習いだけ残るより、誰もいなくなる方を先に避ける）
  3. レベル4は最後
  4. 今日の回数が少ない人から
  5. 同じ人の2時間連続を避ける（3時間連続は固定の前後も含めて禁止）
  6. フロアのカバー：季節AV・家電・情報は3部門で1つのフロア（3人以上残す）、通信は別（1人以上残す）。足りなくなるときは余裕のあるフロアから出す
  7. 役職 PN → 新入社員 → No2 → PNリーダー、同じ役職の中でレベル1 → 2 → 3
  8. まだ入っていない人が多い部門から → 部門のレジ回数を均等に → 人の多い部門 → 日替わり
  - 見習い（レベル0）は自動では入れない（手動でのみ）。時間をタップして「見習いを一緒に入れる」を選ぶと、担当の人と2人で入る（コピーすると「13:00-14:00 石田さん・〇〇さん」）
- プラン：標準（普段はこちら）／バランス（人の少ない部門をフロアに残し、多い部門から出す）／フロア優先（フロアの余裕を優先：通信は2人・ほかの部門は3人残るならそこから出す。閉店前4時間は余裕のある部門の人の2回目を1日1人まで許す）。手動固定は全プラン共通
- 「テキストでコピー」を押した日に、使ったプランと手で直した枠の数をiPad内に記録（名前は記録しない）。ルール表の下に集計を表示
- 時間帯をタップして担当を変更できる（休憩は上長が現場で調整）
- レジ番表の右に、その日の出勤者と時間・レジに入った時間・回数を並べて表示（名前をタップすると、その人のレジの枠が強調される）

## 更新するとき
- アプリ名の横の「v96 · 11/25」が「何回目の更新か・更新した日」。番号は sw.js の `position-v96` と必ず同じにする。日付は左上と、使い方ページの一番下の2か所を書き換える
- 更新前に、旧版から新版への更新・名簿の保持・割り当て・手動変更・コピー・書き出し/読み込み・機内モード・外部通信なしを自動テストで確認する
- 確認が済んだら index.html と sw.js を上書きアップロード。ネットにつながっている時は、アプリを開くたびに最新版を読み込む
- 反映後、iPadでアプリを開き直し、バージョン表示が新しい番号になったことを確認する
- 不具合が出たら、ひとつ前の版のファイルを上書きアップロードすれば元に戻る（名簿は消えない）

## TODO表（v67〜・BETA）

- 「TODO」タブ：その日の作業ごとの実施者を、レジ番と同じ出勤者から自動で決める。印刷すると紙の作業表と同じ形（確認者の欄は手書き用）
- 項目は店ごとに違うので、アプリには見本だけを入れている。店の項目は「項目を編集」で画面の上から直す（v68〜）：区分の名前・対象（◯時より前に出勤／◯時以降に出勤／◯時までいる／始めからいる人／最後までいる人／遅番Lだけ など。「始め」「最後」はその日いちばん早く来る人・いちばん遅くまでいる人、v96〜）・リーダーの項目の担当、項目の追加・削除・並べ替え・担当（区分の対象／リーダー／部門）・背景の色・文字の色（黒・赤）。早番L・遅番Lの基準の時刻も変えられる（遅番Lは、決めていなければ閉店時刻）
- 保存はiPadの中だけ。別のiPad・ほかの店へは、書き出しファイル・QR（TODOだけのQRには名前は入らない）・「テキストでまとめて書き換え」の文で渡せる
- 決め方：黄色＝リーダーの仕事（12:00前に来たリーダーが早番L、閉店までいるリーダーが遅番L）。ほかの項目は区分の条件（出勤・退勤の時刻）に合う人から、リーダー以外で、TODOの数が少ない人 → 同じならランダム の順（v93〜。レジの回数は見ない）。部門の印がある項目はその部門の人から。店長（役職・部門）はふだんの項目には入らず、早番L・遅番Lのリーダーがいない日にリーダーの項目を担当する（v87〜）。部門が流通便の人は入らない。見習い（レベル0）は自動では入れない（手で選べる）
- 「出力」ボタン（印刷）：Safariではそのまま印刷。iPhone・iPadのホーム画面から開いたアプリでは印刷画面を出せないので（Windows・Macでアプリとして入れた場合は普通に印刷できる）、紙と同じ形のA4画像を作り「共有 → プリント」で印刷する（v74）
- 実施者はタップで選び直せる（手動）。シフトを貼り直すと手動変更は消える

## 共有（v51〜、v70でまとめて共有）

- 右上の「共有」で2択：「まとめて共有」（① アプリのURLのQR → ② 名簿とTODOの項目をまとめたQR）／「アプリを共有」（URLのQRだけ）
- 「TODO」タブの「QRで渡す」：TODOの項目だけ（名前は入らない）。ほかの店に項目を渡すときに使う
- 受け取りは「名簿」か「TODO」の「QRで受け取る」。名簿だけ・TODOだけ・まとめて のどれでも読める。名簿だけのQRは前の版と同じ形

- 右上の「共有」：アプリのURLのQRコード。ホーム画面から開いているとURLが見えないので、人に教えるときに使う
- 名簿タブの「QRで渡す」→ 相手の「QRで受け取る」：名簿（名前・部門・役職・レベル・締め・営業時間・部門名）をカメラで移す。インターネットは通らない
  - 名簿は圧縮してQRに入れる。QRは画面いっぱいに表示し、姓名で約100人まではQR1枚。読み取りにくいときは「分けて表示」で小さいQR数枚にできる（とても大きい名簿は最初から分ける）。分けたQRは1.3秒ずつ切り替えて表示し、受け取る側はカメラを向けたままにすれば全部そろった時点で確認が出る
  - QRは1分で自動的に消える。名前とレベルが入っているので、読み取る人以外に見せない
  - カメラが使えないときは「写真から読み取る」（分けたQRは1枚ずつ写真を読む）
