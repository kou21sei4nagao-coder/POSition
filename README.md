# POSition（レジ番メーカー・オフライン版）

その日のシフトを貼り付けると、9:00〜21:00のレジ番を1時間ごとに自動で割り当てるiPad向けアプリです。

## 使い方
1. 「名簿」タブ：シフト表のC列（名前）を一番上から一番下まで、部門の間の空白も含めてコピーして登録（最初の1回と、人が増減した時だけ）
2. 空白で区切られたグループごとに部門を選び、役職・レベルを設定
3. 「今日のシフト」タブ：作りたい日の列を、名簿と同じ行から同じ行までコピーして貼り付け
4. 照合結果で名前と時間がずれていないか確認し、「レジ番表を作る」

## データの扱い
- 名前・シフト・スタッフ設定は、使っているiPadの中（ブラウザの保存領域）だけに保存されます
- 外部へデータを送る処理は入っていません（ページ内の設定で、外部サイトへの通信も禁止しています）
- GitHubに置くのはアプリ本体だけです。実名の入ったファイルはリポジトリに入れないでください

## 公開手順（GitHub Pages）
1. GitHubで新しいリポジトリを作る（例：`regiban`、Public）
2. このフォルダの中身をすべてアップロードする
3. リポジトリの Settings → Pages → Branch を `main` / `(root)` にして Save
4. 数分後に `https://ユーザー名.github.io/regiban/` で開けるようになる

## iPadへのインストール
1. 上のURLをSafariで開く
2. 共有ボタン → 「ホーム画面に追加」
3. 一度開いたあとは、機内モードでも動きます

## バックアップ
- スタッフ画面の「書き出し」で設定をファイルに保存
- 機種変更や別のiPadでは「読み込み」でそのファイルを選ぶと復元

## 割り当てルール
- レジに入るのはPNと副リーダーのみ（リーダー・店長は入らない）
- 部門で「店長」「流通便」を選んだ人は、レジにもフロアの人数にも入らない
- レベル1（優先）→ 2（普通）→ 3（足りない時だけ）→ 0（見習い）の順
- 締めGODにチェックした人を、最後の20:00〜21:00（レジ締め）に優先して入れる。その直前の1時間は締めGODを温存する
- 4部門が均等になるように回す。部門のフロアが0人になる人は外す
- 同じ人の連続は基本避け、どうしても必要な時だけ2時間まで
- 時間帯をタップして担当変更・休憩で外すことができる

## 更新するとき
- ファイルを上書きアップロードするだけでOK。ネットにつながっている時は、アプリを開くたびに最新版を読み込みます
- GitHub側の反映には数分かかります。古い画面のままなら、数分おいてからアプリを閉じて開き直してください
